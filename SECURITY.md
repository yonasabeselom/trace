# Security Policy

## Supported Versions

| Version | Supported |
|---------|----------|
| 1.0     | ✅ Yes    |

## Reporting a Vulnerability

If you discover a security issue in TRACE, please report it responsibly:

- **Email:** yonas_abeselom@protonmail.com
- **Do not** open a public GitHub issue for security vulnerabilities
- Include a clear description and steps to reproduce
- Allow reasonable time for a fix before public disclosure

## Scope

TRACE is a **read-only** forensic scanner — it does not modify, delete, or write any system files.  
Security reports related to false positives, score accuracy, or artifact detection are also welcome.
